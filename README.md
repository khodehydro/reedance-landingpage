# ری‌دنس | Reedance landing page

لندینگ فارسی و راست‌چین ری‌دنس، یک اپ اندرویدی برای یادگیری زبان با موسیقی. سایت استاتیک است و برای اجرا به حساب، پایگاه داده یا سرویس بیرونی نیاز ندارد.

## اجرا و انتشار

با Node.js 22.12 یا جدیدتر:

```sh
npm ci
npm run dev
npm run build
npm run preview
```

برای انتشار، خروجی `dist/` را روی یک میزبان استاتیک قرار دهید. سایت برای انتشار در ریشهٔ دامنه تنظیم شده است.

## منبع طراحی و محتوا

- [60fps.design](https://60fps.design/) مرجع طراحی برای گالری فیلترپذیر، پیش‌نمایش‌های تعاملی و حرکت‌های کوتاه است؛ هیچ تصویر یا کد آن سایت بازنشر نشده است.
- ادعاهای محصول و دارایی‌های برند از [شاخهٔ اندروید](https://github.com/khodehydro/reedance-android/tree/ba9b57a3e60746d1dc41b30e10ae1643dd88e0be) بررسی شده‌اند. لوگو، تصویر استارتر و پرچم‌های انگلیس، اسپانیا، ترکیه و کرهٔ جنوبی از `android/app/src/main/res/drawable-nodpi` و فونت‌ها از `android/app/src/main/res/font` گرفته شده‌اند. مجوز فونت‌ها و آیکن‌های Lucide همراه فایل‌هاست.
- مثال‌های آموزشی در کارت‌های امکانات نمونه‌های مستقل‌اند و بخشی از اپ اندروید نیستند.
- دکمه‌های دانلود به [صفحهٔ ری‌دنس در بازار](https://cafebazaar.ir/app/com.hydro.reedance) با شناسهٔ بستهٔ `com.hydro.reedance` هدایت می‌شوند.
