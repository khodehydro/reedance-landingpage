# ری‌دنس | Reedance landing page

لندینگ فارسی و راست‌چین ری‌دنس، یک اپ اندرویدی برای یادگیری زبان با موسیقی. سایت استاتیک است و برای اجرا به حساب، پایگاه داده یا سرویس بیرونی نیاز ندارد.

## اجرا و انتشار

با Node.js 22.12 یا جدیدتر:

```sh
npm ci
npm run dev
npm run build
npm run preview
```

برای انتشار، خروجی `dist/` را روی یک میزبان استاتیک قرار دهید. سایت برای انتشار در ریشهٔ دامنه تنظیم شده است.

## منبع طراحی و محتوا

- [60fps.design](https://60fps.design/) مرجع طراحی برای گالری فیلترپذیر، پیش‌نمایش‌های تعاملی و حرکت‌های کوتاه است؛ هیچ تصویر یا کد آن سایت بازنشر نشده است.
- ادعاهای محصول و دارایی‌های برند از [شاخهٔ اندروید](https://github.com/khodehydro/reedance-android/tree/ba9b57a3e60746d1dc41b30e10ae1643dd88e0be) بررسی شده‌اند. لوگو، نشان، تصویر استارتر و پرچم‌ها از `android/app/src/main/res/drawable-nodpi` و فونت‌ها از `android/app/src/main/res/font` گرفته شده‌اند. مجوز فونت‌ها و آیکن‌های Lucide همراه فایل‌هاست.
- پلیر وب، متن آموزشی و تمرین‌ها نمونهٔ مستقل هستند، نه اجرای اپ یا بازنشر یک آهنگ تجاری. تصویر پس‌زمینه برای این صفحه تولید شده و صوت بی‌کلام را می‌توان با `python scripts/generate-preview.py` (با نصب `lameenc`) دوباره تولید کرد.
- چون نسخهٔ عمومی اندروید موجود نیست، بخش اندروید به مخزن و کانال رسمی معرفی‌شده در اپ لینک می‌دهد، نه به APK آزمایشی.
